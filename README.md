# NeuroViu™ | Neural Analytics

A premium technology marketing website for NeuroViu™, an advanced neural analytics platform that uses wearable EEG technology and AI-powered analysis to measure, visualize, and improve cognitive performance.

## Key Technologies

- **Framework**: TanStack Start (React 19 + Vite)
- **Routing**: TanStack Router (file-based)
- **Styling**: Tailwind CSS v4 + custom CSS animations
- **Fonts**: Syne (display), Space Grotesk (body), JetBrains Mono (data/code)
- **Deployment**: Netlify

## Design

- Dark neuroscience-inspired aesthetic — deep navy, electric blue, violet
- Animated EEG waveforms and neural network visualizations (pure SVG + CSS)
- Live-updating cognitive metric gauges with smooth transitions
- Glassmorphism cards, radial glow effects, scan-line overlays
- Fully responsive, mobile-first layout

## Sections

1. **Hero** — headline, live EEG analytics dashboard, key metrics
2. **What is NeuroViu** — platform overview with live frequency spectrum analyzer
3. **Key Features** — 8-feature grid with icons
4. **Applications** — 6 use-case domains with interactive brain orbital visual
5. **How It Works** — 4-step process cards
6. **Vision** — brand vision quote with animated waveform bars
7. **Contact & Early Access** — waitlist signup form with role selection

## Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
